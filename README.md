# Sweet Downloader Android
Minimal Android port of Sweet Downloader.

## UI
Heart + URL + Download + status.

## Saved files
Pictures/Sweet/<page title>_<timestamp>/

## Build
Run `gradle assembleDebug` or push to GitHub and download the `Sweet-APK` artifact from Actions.

## Notes
This lightweight Android port downloads discoverable page images from standard HTML/lazy-load/srcset/metadata links. Desktop-only Playwright automation and NudeNet filtering are not bundled in this mobile build.
